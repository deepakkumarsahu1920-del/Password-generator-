# Password Generator

A simple and user-friendly Password Generator Web Application built using HTML, CSS, and JavaScript.

## Project Objective

The objective of this project is to develop a Password Generator Web Application that generates random passwords based on user-defined criteria and demonstrates basic web development concepts.

## Features

- Generate random passwords
- Select password length
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters
- Proper input validation
- Dynamic password generation using JavaScript
- User-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the `Password-Generator` folder.
3. Open `index.html` in a web browser.
4. Select the required password length.
5. Select the desired character types.
6. Click the Generate Password button.
7. The generated password will be displayed on the screen.

## Password Criteria

The application allows users to select:

- Uppercase Letters (A-Z)
- Lowercase Letters (a-z)
- Numbers (0-9)
- Special Characters

## Validation

The application validates the password length and ensures that at least one character type is selected before generating a password.
